
ASUS Xtion Pro CD Readme file

 OpenNI Framework v1.5.5.0
 Sensor DDK v5.1.4.0
 NITE v1.5.2.21
 USB driver v3.1.3.1


*******************************************************
Required software:

for WinXP:
    Microsoft .NET 3.5: http://www.microsoft.com/en-us/download/details.aspx?id=21


for Linux Ubuntu 12.04:
    The installation steps as follows,
    1. install OpenNI package
    2. install Sensor package
    3. install NITE package

    Please install the freeglut3-dev package. You may search for freeglut3-dev package on the Internet by the keyword "freeglut3-dev Ubuntu 12.04".
